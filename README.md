# Logística de Estadio (Sports & Weather Tracker)

# Contexto y Narrativa
**Stakeholder:** Un fanático de los deportes, o un periodista deportivo, que viaja regularmente a partidos en distintos estadios y necesita información rápida para preparar su logística.

**Propuesta de Valor** Normalmente, el usuario tiene que buscar en una plataforma dónde queda exactamente el estadio de un equipo, y luego abrir otra aplicación del clima para buscar las condiciones de esa ciudad en específico. Esta herramienta elimina esa dificultad integrando ambos procesos: al ingresar el equipo, el sistema cruza los datos de ubicación con el clima actual en tiempo real y entrega una sugerencia de vestimenta en un solo paso.
